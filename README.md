# BLACKOUT: Last Signal

Single-player first-person 3D survival horror game, built with Godot 4.4.1.

## Gameplay
- Explore a dark forest and abandoned outpost.
- Use your flashlight and sprint, managing stamina.
- Find three signal fragments while avoiding The Listener.
- Android touch controls and desktop keyboard/mouse controls.

## Build APK
Push to main to trigger **Build Android APK**. When the workflow completes, download the artifact named `BLACKOUT-Last-Signal-APK` from the Actions run. This is a debug APK for testing; a Play Store release needs your own signing keystore.

Desktop: WASD to move, mouse to look, Shift to sprint, E to interact.
Android: drag right side to look; use on-screen MOVE, RUN, USE and LIGHT controls.
